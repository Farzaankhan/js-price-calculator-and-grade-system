# js-price-calculator-and-grade-system
A collection of beginner-friendly JavaScript mini projects featuring a PS5 price calculator with discount logic, random number generator, and marks grading system using DOM manipulation and event handling.
  🚀 JavaScript Mini Projects
A collection of beginner-friendly JavaScript projects built to practice DOM manipulation, event handling, conditional statements, and basic calculations.

✨ Features
🎮 PS5 Price Calculator — Calculate the total price based on quantity.
💸 Discount System — Automatically applies a 10% discount when the total reaches Rs. 500,000 or more.
🎲 Random Number Generator — Generates a random number between 1 and 100 and identifies it as high or low.
📊 Marks Grading System — Displays a grade message based on the entered marks.
🖱️ DOM Manipulation — Updates webpage content dynamically using JavaScript.
⚡ Event Handling — Responds to button clicks and user input.
🧮 Basic Calculations — Uses mathematical operations and conditional logic.
🛠️ Technologies Used
HTML5
CSS3
JavaScript
🎯 Learning Goals
This project helps beginners practice:

Variables and functions
if/else conditions
User input handling
Math.random() and Math.floor()
DOM selection and textContent
Event listeners
Basic arithmetic and discount calculations
🚀 How to Run
Clone or download this repository.
Open the project folder.
Open index.html in your browser.
Try the calculator, random number generator, and grading system.
